如何获取 GitHub Token？

  1. 登录 GitHub，点击右上角头像 → Settings
  2. 左侧底部点击 Developer settings
  3. 点击 Personal access tokens → Tokens (classic)
  4. 点击 Generate new token (classic)
  5. 填写 Note，选择 No expiration
  6. 勾选 ✅ repo（全部勾选）
  7. 点击 Generate token 并复制

📖 详细操作指南

现在您可以一键发布新闻了！配置好 GitHub 设置后，点击"🚀 一键发布"按钮即可自动更新网站。

1 首次配置 GitHub 设置

  1. 点击左侧菜单 "GitHub设置"
  2. 按照页面说明创建 GitHub Token
  3. 填写 Token、仓库所有者、仓库名称
  4. 点击 "保存设置"
  5. 点击 "测试连接" 确保配置正确

2 添加/编辑新闻

  1. 点击 "添加新闻" 按钮
  2. 填写表单内容（标题、分类、日期等）
  3. 点击 "保存新闻"
  4. 数据会保存在浏览器本地

3 🚀 一键发布（核心功能）

  1. 返回"新闻列表"页面
  2. 点击右上角巨大的绿色按钮 "🚀 一键发布"
  3. 系统会自动：
    • 将新闻数据更新到 js/news-data.js
    • 提交到您的 GitHub 仓库
    • Netlify 会自动检测并重新部署网站
  4. 等待 1-3 分钟，网站就会显示最新内容
